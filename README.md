## Projects

**Kathclip**
A web-based video editor that automatically stitches fan-cam clips into beat-synced music videos. React (Vite) frontend with a custom timeline and a dual-buffered preview player; FastAPI backend for beat detection and face tracking; FFmpeg for final rendering. Currently adding support for importing Alight Motion motion-graphics presets.

**Face Restoration via Single-Step Diffusion** — *undergraduate thesis*
Researching a Shared-Image Attention mechanism for restoring degraded face images in a single diffusion step, aimed at reducing inference cost relative to multi-step approaches.

**Guava Disease Classifier**
A CNN-based image classifier distinguishing healthy guava leaves from anthracnose infection, with a comparative evaluation across model variants.
